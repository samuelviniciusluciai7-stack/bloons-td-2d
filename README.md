# bloons-td-2d

Um jogo Tower Defense 2D inspirado em Bloons TD 6, desenvolvido com HTML5 Canvas, Vanilla JavaScript e CSS moderno.

## 🌟 Funcionalidades

- **3 Fases Temáticas com Trajetórias Únicas**:
  - 🌲 **Pradaria Verde**: Trajetória clássica em zigue-zague com 4 curvas na floresta.
  - ❄️ **Pico Congelado (Fase de Gelo)**: Trajetória sinuosa em slalom pelas geleiras com efeitos climáticos de nevasca.
  - 🌋 **Vulcão Ardente (Fase de Lava)**: Trajetória espiral contornando uma caldeira de magma fervente com partículas de brasas incandescentes.
- **Defensores Variados**: Atirador de dardos, Disparador de pregos, Bombardeiro, Torre de gelo, Mago, Super, Sniper, Ninja e Alquimista.
- **Sistema de Upgrades**: Cada torre possui melhorias únicas de alcance, dano, cadência, perfuração (*pierce*) e detecção de camuflagem.
- **Múltiplos Tipos de Balões**: Vermelho, Azul, Verde, Amarelo, Rosa, Preto, Branco, Roxo, Chumbo, Zebra, Arco-íris, Cerâmica e Chefões MOAB/BFB.
- **Modos de Jogo**: Modo Normal com 40 rodadas progressivas e Modo Sandbox com spawner livre.

## 🚀 Como Jogar

Abra o arquivo `index.html` em qualquer navegador moderno ou sirva localmente com um servidor HTTP simples:

```bash
# Com Python:
python -m http.server 8000
```
